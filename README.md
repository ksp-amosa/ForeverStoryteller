# ForeverStoryteller 說書人

《魔獸世界》永恆版本（WoW Forever）的任務說書人插件。在任務與地圖視窗加上說書人聊天面板，用白話講解目前任務、整理任務鏈的來龍去脈，也能直接追問 NPC、地點和物品的故事。回答由電腦上的外部工具處理，可使用本機模型或雲端 AI 服務。

> **請從 [Releases](../../releases/latest) 下載發布的 zip，不要直接下載這個儲存庫的原始碼。** 發布的 zip 附有作者簽章，外部工具會驗證；直接下載原始碼可能和簽章不一致。

## 功能

| 功能 | 說明 |
|---|---|
| 開場摘要 | 選一個任務，說書人依任務鏈整理前情、目前要做的事和人物關係 |
| 任務清單按鈕 | 任務清單每個任務旁有說書人按鈕，點一下直接打開；Shift + 點一下會接著用白話講劇情；Alt + 點一下先重置這條任務鏈的對話，再整理開場摘要並用白話講劇情 |
| 任務分類按鈕 | 點一下把該分類還沒有故事卡的任務排進佇列；Shift + Alt + 點一下重置整個分類的對話並重新講劇情 |
| 回顧故事卡 | 問已完成的任務時，用過去式回顧當時的劇情，引言用當時的 NPC，不會蓋掉進行中任務的故事卡 |
| 背景排隊 | 「全部讀一遍」把任務日誌裡還沒有故事卡的任務排進佇列，在背景一個一個講；接到新任務時可自動排入任務卡或任務卡＋故事卡；排隊超過 3 個時自動套用慢速模式，任務之間的間隔可以調整 |
| 跟上任務鏈 | 交完任務接到同一條鏈的下一個任務時，對話自動跟上並標出「任務鏈前進」，小地圖按鈕直接開到目前的任務 |
| 追問 | 輸入問題或點說書人提供的追問建議，對話依任務鏈分開保存，各角色獨立 |
| 防劇透 | 只用已完成和進行中的任務資料；還沒接的任務只給名稱，不講內容 |
| 三種語氣 | 說書人、老玩家、自訂語氣；切換時已有的段落直接顯示，沒有的才重寫 |
| 關鍵字連結 | 回答裡的 NPC、物品、地點、任務可以點開名片卡、在地圖上標出位置，或複製到聊天輸入框；NPC 名片卡可複製名稱，方便建立巨集 |
| NPC 綽號 | 只限任務相關的 NPC（給任務、交任務、有頭銜或獨特的具名 NPC），依背景取綽號，三種語氣分開；可在名片卡直接修改，或請 AI 重新建議。地點與一般小怪不取綽號 |
| 對話壓縮 | 一般對話超過上下文上限時，壓縮成一則約 200 字的重點；任務卡與故事卡保留原文 |
| 對話封存 | 任務鏈的任務都交完後，對話自動封存：可以繼續翻閱，不能再提問；接回同一條鏈的任務時自動解除。地圖導覽列的「封存」分頁列出所有封存的對話，可以翻閱或刪除。放棄任務則刪除那條鏈的對話 |
| 目標巨集 | 一鍵建立選取任務目標的巨集；收集物品的任務也會依 QuestieDB 加入會掉落該物品的怪 |
| 地圖標記 | 先檢查座標再開地圖，標記成功時用聚光燈效果指出位置；回答中的遊戲地名（含小區域）自動變成地點連結 |
| 複製文字 | 回答可以開啟複製視窗，全選或拖曳選取部分文字 |
| 備援 AI | 主要服務忙碌或逾時時，改用備援模型回答；回答會標「（備援）」 |
| 外部工具選單 | 設定 AI 服務與備援、加密保存 API 金鑰、更新插件與資料庫、開機自動啟動、解除安裝 |

### 聊天指令

| 指令 | 功能 |
|---|---|
| `/fst` | 列出所有指令 |
| `/fst st` | 檢查外部工具連線 |
| `/fst c-check` | 校正色塊條 |
| `/fst env` | 請外部工具檢查執行環境 |
| `/fst open [任務ID]` | 產生開場摘要（加 `!` 重新產生） |
| `/fst say [任務ID] 問題` | 直接問說書人 |
| `/fst style [s\|c\|u]` | 切換說書人／老玩家／自訂語氣 |
| `/fst clear [任務ID]` | 重置這條任務鏈的對話 |
| `/fst clearall` | 清除這個角色的全部對話（綽號不受影響） |
| `/fst nick 本名 綽號` | 修改目前語氣的綽號；不寫綽號就清空，下次遇到時由 AI 重新取名 |

小地圖按鈕：左鍵開啟剛交完、尚未查看的任務（沒有時開啟上次的說書人頁面），Alt + 左鍵全部讀一遍，右鍵開啟設定。

### 支援的 AI 服務（擇一，可另設備援）

- Google Gemini（推薦）：有免費額度，申請金鑰約 1 分鐘。預設主要模型 Flash，備援 Flash-Lite
- 本機模型（LM Studio 等 OpenAI 相容服務）：免費，資料不離開電腦，需要自己安裝模型，建議見下一節
- OpenAI ChatGPT、Anthropic Claude：需要 API 金鑰
- Claude Code：需要 Claude Code 訂閱
- ChatGPT 訂閱：需要已安裝並以 ChatGPT 帳號登入的 [Codex CLI](https://github.com/openai/codex)（`codex login`），回應比 API 慢

已經在用 [ChatTranslate](https://github.com/ksp-amosa/ChatTranslate) 的話，首次設定時可以直接沿用它的 AI 服務與 API 金鑰。

## 建議的本機模型

在 LM Studio 下載以下模型。顯示卡記憶體（VRAM）要扣掉遊戲本身的用量，建議預留 2GB 以上。

| 模型 | 適合的顯示卡 | 說明 |
|---|---|---|
| `gemma-4-e2b-it-qat`（預設） | 8GB 以上 | 約佔 2GB VRAM。RTX 3050 8GB 實測：開場摘要約 13 秒，一般提問約 1 秒 |
| `gemma-4-e4b-it-qat` | 12GB 以上 | 約佔 4GB VRAM，細節比 e2b 好。8GB 顯示卡實測太慢（開場摘要約 50 秒），不建議 |
| `gemma-4-26b-a4b-it`（Q4 量化） | 24GB（16GB 可勉強） | 模型約 16GB。每次只啟用約 4B 參數，速度接近小模型，品質明顯較好。16GB 顯示卡需要把部分專家層卸載到系統記憶體（建議 32GB 以上）。尚未實測 |

模型越小，越容易講錯細節或漏掉追問；品質需求高的話，建議改用 Gemini。

## 運作方式

插件無法連網，所以回答交給遊戲外的工具，兩邊只透過遊戲允許的方式交換資料：

- **遊戲 → 外部工具**：插件在畫面最左上角畫一條 1 像素高的色塊條（「HDR／濾鏡相容」模式是 2 像素高、橫跨整個上緣，每條自帶參考色），外部工具擷取遊戲視窗最上方 2 列畫面讀出內容。只送任務 ID、問題和玩家在遊戲中看過的任務文字。
- **外部工具 → 遊戲**：外部工具寫入插件資料夾內的快取圖片（`slots`），插件讀取圖片的寬高還原文字。遊戲只在登入或 `/reload` 時掃描檔案，所以每次 `/reload` 有固定數量的快取（預設 5000）。
- **任務與 NPC 資料**：外部工具在執行時讀取 [QuestieDB](https://github.com/Questie/QuestieDB) 與（可選的）[VMaNGOS](https://github.com/vmangos/core) 經典版資料庫，不隨插件附帶；NPC 背景從 [warcraft.wiki.gg](https://warcraft.wiki.gg) 的公開 API 查詢，可在設定中關閉。

不讀取、不修改遊戲記憶體，不注入程式，不模擬鍵盤滑鼠。本插件未經 Blizzard 審核或認可，是否使用請自行評估。

## 系統需求

- Windows 10 / 11
- [uv](https://github.com/astral-sh/uv)：外部工具用它準備 Python 環境，不需要另外安裝 Python。第一次執行時若找不到 uv，可選擇自動安裝或自行安裝。
- QuestieDB：外部工具的選單可以自動下載安裝。

## 安裝

1. 從 [Releases](../../releases/latest) 下載 `ForeverStoryteller-版本.zip`。
2. 解壓縮到遊戲目錄的 `Interface\AddOns`，完全關閉遊戲後重新開啟。
3. 雙擊 `ForeverStoryteller\Tool\ForeverStoryteller.bat`，選「6. 首次設定引導」：依序設定 AI 服務與金鑰、聊天字型、開機自動啟動，最後在背景啟動說書人工具。每一步直接按 Enter 就是建議選項。
4. 選「3. 更新插件與資料」安裝 QuestieDB（說書人需要它）；經典版資料庫可選裝，在「4. 經典版資料庫」下載。
5. 完全關閉遊戲再重開（第一次放字型和裝 QuestieDB 都需要），打開地圖的任務日誌就會看到說書人。

## 更新

雙擊 `ForeverStoryteller.bat` 選「3. 更新插件與資料」。有新版本時可以直接從 GitHub 下載，也可以使用自己下載的 zip（不用解壓縮）。工具會驗證作者簽章後才更新，並先備份目前的版本。QuestieDB 與經典版資料庫也在這裡更新。

## 安全性與隱私

- 不需要系統管理員權限。
- 網路只連到：你選的 AI 服務、warcraft.wiki.gg（NPC 背景，可關閉）、wago.tools（繁中地區名稱）、GitHub（檢查更新、下載 QuestieDB 與經典版資料庫，玩家確認後才下載）。第一次執行時 uv 會下載 Python 與套件。不回傳使用紀錄。
- 對外查詢只送 NPC 英文名稱等公開資料，不送任何玩家資料。
- API 金鑰只在外部工具設定，不會在遊戲裡輸入或保存；以 Windows DPAPI 加密保存在 `%LOCALAPPDATA%\ForeverStoryteller`，只有同一台電腦的同一個 Windows 帳號能解開，畫面上只顯示末 4 碼。
- 對話紀錄只存在本機；使用雲端服務時，任務資料和你的問題會送到該服務。
- 選單「7. 解除安裝」可逐項刪除所有資料。
